# 문학의 형태별 탐색 프로젝트

이 프로젝트는 문학의 형태를 시각적으로 정리한 단일 페이지 웹앱입니다.

## 포함 내용
- 시
- 소설
- 희곡
- 수필
- 서사시
- 평론

## 실행 방법
1. 브라우저에서 `index.html` 파일을 직접 열어도 됩니다.
2. 로컬 서버로 실행하려면 아래 명령어를 사용하세요.

```bash
python -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000`으로 접속하면 확인할 수 있습니다.

## 구성
- 카드형 문학 형태 소개
- 형태별 필터 버튼
- 키워드 검색 기능
- 선택한 문학 형태의 상세 설명
